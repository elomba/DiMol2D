EXPERIMENT 2: Crystallization from a high density fluid

  • Initial Conditions
    1. Select from the Main Panel a high temperature (T~1.0) and set the density to 0.86 )
    2. Choose from the menu Simulation type the Option Pure Substance
    3. Visualize the shape of the interaction potential using the Option Interactions from the menu System Control
    4. Using the slider rule set the range of the potential to Rc=2.5
  • Fluid phase simulation
    1.  Start the simulation at the conditions indicated above pressing the Start option from the Control Popup Menu. If needed activate the Option Pair distribution function from the menu System Control
    2. Observe the typical characteristics of a high density fluid, both in the spatial distribution of the particle (see note at the bottom of page) and in the distribution function.
  • Solid phase simulation
    1. Stop the simulation (Pause option in the Popup Menu)
    2. Lower the temperature (at constant density 0.86) until a temperature where phase coexistence no longer exists (T~0.40) (observe the position of the selected state point in the phase diagram)
    3. Restart the simulation (Go on option in the Popup Menu). Observe the qualitative change (see note at bottom of page) in the system structure (now in a crystalline phase)

    NOTICE: It might be useful to momentarily stop the simulation (Pause option in the Control Popup Menu) and then activate the option Paint bonds from the menu System Control, in order to better appreciate the particle ordering.
