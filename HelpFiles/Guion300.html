Binary mixtures


EXPERIMENT 1: Miscibility between two fluids
  • Initial conditions
    1. Select from the menu Simulation Type the Option Binary mixture
    2. Select an intermediate temperature and density
    3. Activate, if needed, the Option Phase diagram from the System menu
    4. Observe the phase diagram:
      • This phase diagram corresponds to potential cutoffs Rc=2.50 for same like particle and Rc=1.12 for pairs of particles of different species
      • Grey areas represent conditionos of temperature and density for which an equimolar mixture separates in two phases with the same density but different composition (demixing).
      • Select conditions of density and temperature corresponding to a demixing zone (labeled as A+B on the phase diagram).
      • Confirm that the A-A cutoff is set to 2.50 and 1.12 for the A-B interaction using the Option Interactions from the System menu.


  • Simulation
    1. Start the simulation run using the Option Start from the Control Popup Menu
    2. You can see that particles of the same type (color) tend to aggregate until the system splits into two zones.
  • Comment (on thermodynamics)
    1. Demixing is favored by the fact that particles of the same type attract each other (see the attractive well in the interaction plot) to a large extent than particles of different type. This induces an decrease of the internal energy in parallel with the demixing. This compensates the raise in entropy inherent to the demixing process.
