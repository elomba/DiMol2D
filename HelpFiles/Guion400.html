Three component mixtures

EXPERIMENT 1: Kinetics of phase separation

  • Purpose

    In this experiment we intend to visualize how fast a three component homogeneous mixture separates in three condensed phases (each of them with one majoritary component) when particles interact with potentials that favor attraction between like particles. To that aim we will perform three experiemtns at the same temperature and three different densities. The first density is that of a fluid, the second corresponds to a solid near meltin and the third to a high pressure solid (high density).

  • Method
    1. Select Ternary mixture from the menu Simulation type
    2. Select an intermediate temperature and density
    3. Activate, if needed, the Option Phase diagram from the System menu and adjust temperature and density until entering the region where the fluid demixes in three phases (labeled A+B+C on the phase diagram), for instance T~0.55, and density within the range (0.50,0.80)


    4. Observe the phase diagram:
      • This diagram corresponds to a cutoff Rc = 2.50 for like interactions and Rc=1.12 for unlike interactions.
    5. Grey regions represent temperature and density conditions for which an equimolar mixture demixes in three phases, each of them at the same density but with a different majoritary component.
    6. Make sure that the cutoff values are set to 2.50 and 1.12 for like and unlike interactions using the Option Interactions from the System menu.
  • Simulation
    1. Start the simulation run using the Option Start from the Control Popup Menu
    2. You can see that particles of the same type (color) tend to aggregate. If the density is not two high the system might, in a reasonable time, separate in three areas, each of them containing mostly particles of one species (one must bear in mind the periodicity of the system to analyze whether the system has reached this limit or not).
    3. Using the Pause Option from the Control Popup Menu, stop the simulation run, change the density until reaching the solid region in the vicinity of solid-fluid coexistence line (density ~ 0.86-0.87)
    4. Restart the simulation using the Start Option from the Control Popup Menu
    5. Observe how in this situation particle diffusion is considerably slower and phase separation will only take place after a much longer time.
    6. Stop again the simulation and increase the density up to the maximum allowed value (density = 1.00). Restart the simulation. In this case, after a few steps particle positions do not change (except for the crystal lattice vibrations) for long simulation times.

  • A kinetic comment
    1. Despite being thermodynamically favored, demixing of the solid phases in our examble is extremely slow. Conclusion: A feasible phase transition from the thermodynamic standpoint might not take place on kinetic grounds.
